## 9. CI/CD and repo hygiene (steps 4–5, summarised)

- `ci.yml` runs only for `main`/`dev`, so **no redesign PR has ever run CI**. Node is hard-coded as `24`; there's no `.nvmrc`. The format step already fails. The e2e job builds against secrets that may not exist.
- No Dependabot, CodeQL, gitleaks, PR-title check, Lighthouse CI, CODEOWNERS or issue/PR templates. There's no `.editorconfig`.
- `package.json` has no description, repository, homepage or keywords, and `version` is `4.0.1`.
- Releases: `standard-version` is deprecated (archived upstream, and it pulls in the handlebars criticals). I recommend **release-please** (a GitHub Action, PR-based, no local tooling, and its changelog keeps the Conventional Commits sections). I'll implement it in step 4 unless you object.
