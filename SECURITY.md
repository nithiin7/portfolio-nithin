# Security policy

## Reporting a vulnerability

Please report security issues **privately** through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue.

Include the affected URL or file, steps to reproduce and the impact you see. You'll get an acknowledgement within 72 hours and a fix or mitigation plan within 14 days for confirmed issues.

## Scope

- The site at https://portfolio-nithin.vercel.app and its API routes (`/api/*`).
- This repository's code and CI configuration.

Out of scope: third-party services the site embeds (Hugging Face Space, Google reCAPTCHA, EmailJS), denial-of-service and volumetric testing, and social engineering.

## Supported versions

Only the latest deployment of `main` is supported.
