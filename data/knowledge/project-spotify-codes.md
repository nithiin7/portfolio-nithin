# Project: Spotify Codes

## Overview

Spotify Codes is a Spotify internal tooling project (Kochi, offsite) that Nithin Pradeep contributed to as a backend and full-stack developer from Jan 2024 to Jul 2025 (full time). He built and maintained API services in PHP and Node.js, handling data processing and integration requirements specific to Spotify's internal operations workflow. Tech used: PHP, Node.js, REST APIs, Backend Engineering.
