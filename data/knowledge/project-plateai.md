# Project: PlateAI

## Overview

PlateAI is a vision-driven recipe application built by Nithin Pradeep as a freelance project (Kochi, offsite) from Sep 2025 to Oct 2025 (full time). It uses computer vision and LLM pipelines to analyze ingredient images and return personalized recipes with step-by-step cooking instructions. PlateAI is built with Python, LangGraph, and a multimodal vision model for image analysis, integrated with a vector database (ChromaDB) for ingredient matching and recipe retrieval via RAG. Tech used: Python, LangGraph, RAG, ChromaDB, Computer Vision, MCP, Nginx.
