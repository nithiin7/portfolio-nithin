# Project: Arcwise

## Overview

Arcwise is an AI-powered system design coach built by Nithin Pradeep as a personal project from May 2026 to Jun 2026 (full time). It is built with Next.js, FastAPI, and Claude. Features include AI-guided clarification, real-time Mermaid.js architecture diagram generation, iterative chat-based refinement, and scored feedback across 5 design dimensions. Arcwise supports multi-model LLM switching (Claude, GPT-4o, Gemini, Groq) via LiteLLM, JWT/OAuth authentication, session sharing, and Docker-based deployment.

## Scoring System

Arcwise's scored feedback system, built by Nithin Pradeep, evaluates system design submissions across 5 dimensions: functional coverage, NFR (non-functional requirement) handling, component justification, tradeoff awareness, and overall design quality.
