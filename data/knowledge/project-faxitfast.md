# Project: FaxitFast

## Overview
FaxitFast is a full-stack enterprise web application built by Nithin Pradeep for client FaxitFast (Kochi, offsite) from Sep 2023 to May 2025 (full time), using the Laminas (Zend) PHP framework. It handles document faxing and digital communication workflows. Nithin developed backend modules, REST API endpoints, and frontend UI components for this business-facing SaaS platform. Tech used: PHP, Laminas, REST APIs, MySQL, Full Stack Development.
