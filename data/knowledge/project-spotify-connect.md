# Project: Spotify Connect

## Overview

Spotify Connect is an internal Spotify web platform that Nithin Pradeep worked on as a full-stack developer (Kochi, offsite) from Jan 2023 to Jul 2025 (full time), building and maintaining both frontend and backend. He implemented SSR pages using Next.js and managed dynamic content delivery through Contentful CMS. Nithin contributed to CDN optimization that helped achieve 50% faster load times for 1M+ concurrent users. Tech used: Next.js, Node.js, Contentful CMS, CDN, SSR, REST APIs, TypeScript. The platform is at https://connect.spotify.com/.
