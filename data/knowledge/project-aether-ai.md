# Project: Aether AI

## Overview

Aether AI is a full-stack multimodal AI assistant built by Nithin Pradeep as a personal project from Nov 2025 to Dec 2025 (full time). It features chat, voice interaction, research modes, and contextual memory for natural, human-like conversations and deep reasoning. The frontend uses Next.js 15 + React with the Vercel AI SDK, supporting multiple model providers (xAI Grok, OpenAI, Anthropic). The backend uses Python Flask with Ollama for local LLM inference and LangChain tool integration.

## Features

Aether AI, built by Nithin Pradeep, supports real-time SSE streaming, persistent chat history stored in Neon PostgreSQL, document creation and editing, and multi-model switching. It also includes scaffolded RAG, voice features (Whisper/TTS), and research agent modes, and is designed for full local or cloud deployment.
