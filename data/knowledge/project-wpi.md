# Project: WPI

## Overview
WPI is a full-stack web application built by Nithin Pradeep for the client WPI (Kochi, offsite) from Feb 2025 to Jul 2025 (full time), developed using Next.js for the frontend and Node.js for the backend API layer. The app helps users search for the different partners their organization is part of, with filtering, search, and partner info lookup. Tech used: Next.js, Node.js, Full Stack Development.
