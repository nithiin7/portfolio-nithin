# Project: The Game Awards

## Overview
The Game Awards is the official platform for The Game Awards, a globally recognized entertainment event website used by 8M+ people during its annual broadcast. Nithin Pradeep contributed as a React UI Developer on the project for client Geoff (Kochi, onsite) from Oct 2023 to Feb 2025 (full time). He delivered pixel-perfect, highly design-specific UI components in React.js, working within strict brand guidelines and performance budgets to handle surge traffic during live event periods, and integrated a WordPress CMS with a decoupled frontend architecture. Tech used: React.js, WordPress, REST APIs, CSS Animations, Responsive Design, Performance Optimization. The site is at https://thegameawards.com.
