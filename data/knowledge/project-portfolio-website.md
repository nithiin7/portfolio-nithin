# Project: Portfolio Website

## Overview

Nithin Pradeep's personal developer portfolio website was built as a freelance project (Kochi, offsite) from Mar 2023 to Apr 2023 (full time), using Next.js (App Router) with Contentful as a headless CMS backend, deployed on Vercel. Features include SSR/SSG page rendering, a dynamic project showcase, blog integration, and responsive design. Tech used: Next.js, Contentful CMS, Vercel, SSR, TypeScript, Responsive Design. The site is live at https://portfolio-nithin.vercel.app/.
