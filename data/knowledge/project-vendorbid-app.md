# Project: VendorBid App

## Overview
VendorBid App is a full-stack bidding and vendor management web application built by Nithin Pradeep for a non-disclosable client (Kochi, offsite) from May 2022 to Jul 2025 (full time), integrated with HubSpot CRM. He built a React.js frontend for deal creation, vendor comparison, and bid management workflows, and developed a Node.js backend with REST APIs to interface with HubSpot's deals API, enabling real-time deal tracking and automated vendor workflows. Tech used: React.js, Node.js, HubSpot API, REST APIs, CRM Integration.
