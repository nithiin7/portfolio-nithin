# Project: Persona

## Overview
Persona is an open-source, self-hosted AI resume builder built by Nithin Pradeep as a personal project from Dec 2025 to May 2026 (full time), using Next.js 15 and React 19. Users paste a job description and Persona uses AI (Claude, GPT, or local Ollama models) to tailor their resume in real time, with live PDF preview, ATS scoring, keyword highlighting, cover letter generation, and a Kanban-based job application pipeline. It supports multiple AI providers (Anthropic, OpenAI, OpenRouter, Ollama) and exports resumes as PDF or DOCX. Persona was built as a fully unlocked fork with no paywalls or subscriptions.
