# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work, and don't harass anyone in issues, pull requests or discussions.

Report unacceptable behaviour to the maintainer through the [contact page](https://portfolio-nithin.vercel.app/contact). Reports are handled confidentially. The maintainer may remove comments, close threads or block accounts that break these rules.
